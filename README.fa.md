# پروژه مستقل FTI

**اصلاح جدید باینری و قفل توکن:** شاخه `fix/funded-binary` برداشت پاداش از بودجه نامرتبط را با اعتبار اختصاصی هر مسیر و سقف واقعی ۲۰ دلار برای هر امتیاز اصلاح می‌کند. این تغییر، فرمول پورسانت را عوض می‌کند؛ بودجه مصرف‌نشده ذخیره محافظت‌شده و غیرقابل‌برداشت است، نه سود یا اصل پول قابل‌استرداد. محدودیت ۶۴ قفل فعال حذف و تسویه اعضای دارای تغییر جدا شده است. [جزئیات و محدودیت‌ها](docs/FUNDED-PLAN.md). اجرای مستقل: `npm run demo:funded` روی پورت محلی ۳۰۸۳. این نسخه روی قرارداد یا سایت زنده اعمال نشده است.

**نسخه جدیدِ آزمایشی توکن:** شاخه `feat/reserve-token` مدل ذخیره واقعی با کارمزد ۳٪ خرید، ۳٪ فروش و سوزاندن ۳٪ انتقال را اضافه می‌کند. اثبات ریاضی، سهم دائماً قفل‌شده، محدودیت‌ها، تست EVM با ۱۰۰ کاربر و شبیه‌سازی حسابی ۳۰۰هزار کیف‌پول در [راهنمای نسخه جدید](docs/RESERVE-TOKEN.md) آمده است. اجرای مستقل: `npm run demo:reserve` روی پورت محلی ۳۰۸۲. این نسخه روی قراردادهای فعلی تست‌نت اعمال نشده و سلامت کل پلن باینری یا سود کاربران را تضمین نمی‌کند. دستورهای قدیمی زیر مربوط به مدل قبلی هستند.

نسخه ۰٫۱ یک بسته مستقل و قابل اجرای محلی و BNB Testnet است: قرارداد باینری، توکن با منحنی خریدوفروش، حاکمیت، پنل فارسی، مجری تسویه و تست‌ها. این نسخه ممیزی مستقل نشده و برای دریافت پول واقعی یا استقرار Mainnet آماده اعلام نمی‌شود. اسکریپت استقرار، شبکه اصلی را رد می‌کند.

## اجرای سریع روی کامپیوتر یا سرور

Node.js نسخه ۲۲ یا جدیدتر لازم است.

```bash
cd fti-protocol
npm ci
npm test
npm run demo
```

سپس http://localhost:3000 را باز کنید. این دستور شبکه محلی، ۴۵ حساب آزمایشی، ۳۱ جایگاه اولیه، پنج امضاکننده شورا، توکن تتر آزمایشی، قراردادها، پنل و مجری تسویه را بالا می‌آورد. حساب اول نمونه Builder 1 است؛ اعداد پنل از قرارداد محلی خوانده می‌شوند. هر بار اجرای demo زنجیره جدید و حساب‌های جدید می‌سازد؛ برای نگهداری آزمایش‌های بلندمدت از Testnet استفاده کنید.

در حالت محلی هیچ پول واقعی وجود ندارد. انتخاب حساب از داخل پنل، فقط برای آزمایش مجاز است. این حالت را روی اینترنت عمومی منتشر نکنید. کلید حساب‌های محلی داخل بسته یا خروجی ثبت نمی‌شود.

## اجرای Docker

```bash
docker compose up --build
```

پورت فقط روی localhost باز می‌شود. برای دیدن پنل سرور از رایانه شخصی:

```bash
ssh -L 3000:127.0.0.1:3000 USER@SERVER
```

آنگاه http://localhost:3000 را باز کنید. این بسته Docker یک آزمایشگاه محلی است؛ سرویس واقعی تولید نیست.

## فایل‌های اصلی

- `contracts/BinaryPlan.sol`: ثبت‌نام و خرید واحد، درخت، انتشار حجم مرحله‌ای، رتبه و سقف، دوره ساعتی، بدهی قابل برداشت، استخر ماهانه و خرید خودکار.
- `contracts/FTIToken.sol`: ERC20، منحنی با توان ۵، ذخیره واقعی و مجازی، کارمزدها، سوزاندن انتقال، مجوز خرید و قفل‌ها.
- `contracts/Governance.sol`: شورای ثابت ۳ از ۵ و Timelock استاندارد ۷۲ساعته.
- `contracts/MockUSD.sol`: فقط توکن آزمایشی؛ faucet عمومی و ابزار شبیه‌سازی انتقال ناموفق دارد. این توکن پشتوانه دلاری ندارد.
- `core/reference.mjs`: مدل مستقل BigInt برای تطبیق محاسبات و حسابداری یکپارچه.
- `scripts/keeper.mjs`: انتشار حجم، تسویه ساعتی، تسویه ماهانه و اجرای خرید خودکار دارای بودجه.
- `web/`: پنل فارسی واکنش‌گرا، اتصال کیف‌پول و عملیات قراردادها.
- `test/`: تست محاسبات و تراکنش واقعی روی EVM محلی.
- `docs/DECISIONS.fa.md`: فرض‌های اقتصادی جدید و تفاوت با ورودی اولیه.
- `docs/OPERATIONS.fa.md`: اجرای آزمایشی و نگهداری سرویس‌ها.
- `docs/test-results.txt`: خروجی آخرین اجرای تست تحویل‌شده.
- `docs/simulation-2000.json`: نتیجه سناریوی ۲۰۰۰ عضو؛ اعداد ۱۸ رقم اعشار دارند.

## آزمایش سناریو

```bash
npm run simulate -- 2000 42
```

ورودی اول تعداد کیف‌پول و ورودی دوم seed است. این مدل، پول ثبت‌نام را ۹۰/۵/۴/۱ تقسیم می‌کند؛ خرید خودکار از طلب واقعی عضو کسر می‌شود. پس از توقف ورودی پول، تمام توکن‌های واقعی، با فرض پایان قفل‌ها، فروخته می‌شوند و بقای وجه و نامساوی دقیق ذخیره بررسی می‌شود. این سناریو، تضمین سود یا آزمون ظرفیت گس برای میلیون‌ها عضو نیست.

## استقرار BNB Testnet

۱. فایل `deployments/testnet-input.example.json` را با نام `testnet-input.json` کپی کنید و ۳۱ آدرس یکتای Genesis، پنج آدرس یکتای شورا و آدرس توسعه را درج کنید. Genesisها در شروع واحد، توکن یا پاداش تأمین‌نشده ندارند.

۲. مقادیر `.env.example` را در محیط امن سرور تنظیم کنید. کلید خصوصی را در چت ارسال نکنید. اسکریپت‌ها فایل env را خودکار بارگذاری نمی‌کنند؛ از قابلیت `--env-file` در Node.js یا مدیر سرویس استفاده کنید.

```bash
npm run compile
node --env-file=.env scripts/deploy.mjs
node --env-file=.env scripts/server.mjs
```

در ترمینال جدا:

```bash
node --env-file=.env scripts/keeper.mjs
```

آدرس‌های واقعیِ ایجادشده در `deployments/testnet.json` ذخیره می‌شوند. توکن پرداخت این نصب عمداً تتر آزمایشی است. برای تراکنش کیف‌پول و مجری به BNB آزمایشی نیاز دارید.

۳. کیف‌پول مرورگر را روی شبکه ۹۷ بگذارید. از پنل توکن آزمایشی بگیرید، به یک برگ درخت معرفی شوید و عملیات را امتحان کنید. UI برای تتر فقط به اندازه همان عملیات اجازه خرج‌کردن می‌گیرد.

## وضعیت تحویل

کد، ابزار اجرا و آزمون محلی در این بسته ارائه می‌شود. هیچ قرارداد عمومی یا دامنه‌ای بدون وجود RPC، آدرس‌های نهایی و هزینه گس شما مستقر نشده است. پنل به قرارداد متصل می‌شود؛ API امضای تراکنش کاربران را انجام نمی‌دهد. یک فایل ZIP به‌تنهایی به معنی استقرار عمومی نیست.

برای آماده‌سازی شبکه اصلی لازم است تصمیم‌های اقتصادی ثبت‌شده نهایی شوند، ممیزی مستقل قرارداد و وابستگی‌ها انجام شود، تست‌های خصمانه و بار واقعی توسعه پیدا کند، توکن پرداخت اصلی و نشانی‌ها قطعی شوند و زیرساخت عملیاتی با پشتیبان و مانیتورینگ راه‌اندازی شود.
