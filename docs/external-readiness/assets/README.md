# CoinMarketCap Community profile artwork

`fti-community-400.png` is a 400 × 400 PNG rendered from the project's existing
`marketing/telegram/assets/site-logo-profile.svg`, which embeds the same
user-supplied artwork used by `frontend/header-mark.jsx`. The SVG contains a
photographic image; it is not a transparent vector cutout. The original dark
background is intentionally retained.

The [CMC Community verification guide](https://coinmarketcap.com/academy/article/get-verified-on-cmc-community-start-building-your-community)
specifies a square 400 × 400 PNG for a project profile. This local asset does
not mean that the project is listed, verified, or that this file has been
published at a public URL or submitted to CoinMarketCap. A separate transparent
listing-form image remains unprepared.

- Source SVG SHA-256: `dd75e00717a23f93b35988d6a9524e2f66524146e9f53bf8bc2442791d817da2`
- PNG SHA-256: `bc0e93ffd383263e1a46badba240ac2415f03db05f19f337e5dcad53a2ce875b`

The SVG was rendered with Sharp at density 150 and resized to 400 × 400 pixels.
Visual review confirmed the retained artwork and dark background.
