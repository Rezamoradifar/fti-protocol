# نسخه مشترک FTI برای آماده سازی تست نت

شناسه انتشار `FTI_V3_INTEGRATED_20261008` است. قرارداد، ABI، فرانت، صفحه معرفی و Keeper در شاخه PR #10 جمع شده‌اند. هنگام اجرا، SHA کامل checkout، اثرانگشت فایل‌های اجرایی و هش artifacts در پیکربندی دیپلوی ثبت می‌شوند. آدرس‌ها و تراکنش‌های نسخه‌های قبلی، آدرس این نسخه محسوب نمی‌شوند.

## رفتار همین نسخه

| موضوع | رفتار اجرایی |
|---|---|
| خیریه | حذف کامل کیف‌پول و صدور توکن خیریه |
| خرید و فروش | کارمزد ۳٪ در ذخیره قیمت‌گذاری باقی می‌ماند |
| انتقال | انتقال معمول ERC20 بدون کارمزد؛ اختلاف با متن قدیمی ۳٪ سوزاندن هنوز تصمیم اقتصادی باز است |
| صدور اولیه | عرضه و ذخیره صفر؛ تزریق عضویت توکن ایجاد نمی‌کند |
| قیمت | نسبت ذخیره قیمت‌گذاری به عرضه؛ گرد کردن صدور رو به پایین |
| حمایت عضویت | ۵ از هر ۱۰۰ در supportReserve مستقل؛ در این کد حتی پس از شروع عرضه مستقل می‌ماند |
| تقسیم عضویت | ۹۰ اعتبار پوینت، ۵ حمایت، ۴ سازنده، ۱ طلب توسعه‌دهنده؛ این ۱ خیریه نیست |
| خرید مجدد | addUnits در همان جایگاه و با پرداخت واقعی ممکن است |
| Reward | پورسانت نقدی مستقیماً به ذی‌نفع ثبت‌شده؛ حداکثر ۱۰۰ حساب در هر تراکنش و ادامه با Keeper |
| خودکار | انتخابی؛ ۵٪ پاداش تسویه ساعتی کنار گذاشته می‌شود؛ شکست خرید، موجودی را برای تلاش مجدد حفظ می‌کند |
| سقف خرید | پایه رتبه به ازای واحد عضویت؛ ضریب Builder با هر ۱۰ برابر launchPrice دو برابر، حداکثر ۱۶ برابر |
| سقف فروش | هر فروش ناخالص حداکثر ۵٪ ذخیره و خروج خالص ساعتی حداکثر ۲۰٪ ذخیره آغاز پنجره |
| حاکمیت عادی | شورای ۵ از ۷ عملیات را در FTITimelock ثبت می‌کند؛ اجرا پس از ۷۲ ساعت |
| اضطراری | شورای ۵ از ۷ توقف یا بازخرید تناسبی برگشت‌ناپذیر را اجرا می‌کند |

سقف‌های پوینت ساعتی برای Member تا Builder IV در سطح حفاظت صفر، ۵، ۱۰، ۱۵، ۲۰ و ۲۵ است. سطوح حفاظت بعدی `[5,10,12,16,20]`، `[5,10,10,12,15]` و `[5,10,10,10,10]` هستند. پاداش هر پوینت حداکثر ۲۰ و محدود به اعتبار منتسب به حجم پرداخت‌شده همان شاخه است؛ ذخایر باقی‌مانده و طلب توسعه‌دهنده پشتوانه خریداران تازه نیستند.

## اختلاف های اقتصادی برای تصمیم مالک

متن گزارش تجمیعی، انتقال با سوزاندن ۳٪، ورود حمایت جدید به R پس از مثبت شدن S، خرید خودکار از پاداش سازنده و خروج آخرین دارنده را مطرح می‌کند. کد فعلی رفتارهای جدول بالا را دارد. تغییر این موارد و حذف یا استثناگذاری سقف فروش، بخشی از اصلاح هماهنگی فنی نیست و بدون تصمیم صریح اجرا نشده است. این بسته تأیید نهایی مدل اقتصادی یا آمادگی مین‌نت نیست.

## ساخت و بررسی نسخه ثابت

در checkout گیت، SHA کامل نسخه انتخاب‌شده را ثبت و همان checkout را برای همه سرویس‌ها استفاده کنید:

```bash
git rev-parse HEAD
npm ci
npm run build:web
npm test
```

`npm test` همه فایل‌های تست را در چهار فرایند مستقل اجرا می‌کند. شبکه‌های محلی و فایل‌های موقت تست مستقل‌اند. تست بار قدیمی که نزدیک مرز ساعت شکست می‌خورد، اکنون تاریخ ثابت و افزایش زمان یک ثانیه در هر بلاک دارد؛ شرط تسویه قرارداد تغییر نکرده است.

## آماده سازی اجرای مالک روی شبکه ۹۷

کلیدها فقط در محیط محافظت‌شده سرور تنظیم شوند. مقدار آن‌ها را وارد چت، کد یا لاگ نکنید. `RPC_URL`، `DEPLOYER_PRIVATE_KEY`، `KEEPER_PRIVATE_KEY` و `DAO_CONFIG` پیش‌شرط‌های اجرا هستند. فایل DAO باید هفت آدرس یکتا و حد نصاب ۵ داشته باشد.

پس از قبولی آزمون و تعیین تکلیف اختلاف اقتصادی:

```bash
npm run deploy:v3:testnet
```

اسکریپت فقط شبکه ۹۷ یا شبکه محلی ۳۱۳۳۷ را می‌پذیرد؛ شبکه ۹۷ به SHA کامل نیاز دارد. قراردادها به ترتیب MockUSD، SevenGuardianCouncil، FTITimelock، FTIReserveTokenV3، FundedBinaryPlan و سپس bind ساخته می‌شوند. خروجی شامل پارامترهای سازنده، receipt موفق، هش کد هر قرارداد، آدرس‌ها و نسخه ساخت است. کلیدهای کمکی فقط در فایل محلی با دسترسی 0600 می‌مانند.

```bash
DEPLOYMENT_FILE=deployments/v3-testnet.json npm start
DEPLOYMENT_FILE=deployments/v3-testnet.json npm run keeper
```

فرانت و Keeper قبل از شروع، تطابق اثرانگشت منابع و artifacts، chainId، کد قراردادها، اتصال token/binary، نقش‌های حاکمیت، اعضای شورا و تأخیر ۷۲ ساعت را کنترل می‌کنند. Keeper قدیمی بدون قابلیت batchedRewards تابع صف جدید را فراخوانی نمی‌کند.

در این تغییر هیچ تراکنش شبکه عمومی یا استقرار مین‌نت انجام نشده است. آزمون دیپلوی، رأی‌گیری، انتظار ۷۲ ساعت و API در شبکه محلی شبیه‌سازی می‌شوند. اجرای واقعی شبکه ۹۷ و تطبیق تراکنش‌ها پس از اجرای مالک جداگانه ثبت می‌شود.
