# تکمیل متن مین‌نت و بررسی Keeper

وب اصلی اکنون به شبکهٔ ۵۶ و قراردادهای تأییدشده متصل است. این تغییر متن قدیمی «دارایی آزمایشی بگیرید» را برای مین‌نت با راهنمای اتصال ولت، موجودی، عضویت و معامله جایگزین می‌کند. متن جایگزین به هر هفت زبان رابط ترجمه شده است. توضیح HTML نیز دیگر پنل را تست‌نت معرفی نمی‌کند. حالت واقعی از تنظیمات قرارداد خوانده می‌شود؛ faucet فقط در شبکهٔ آزمایشی فعال می‌ماند و تغییر زمان/حساب‌های محلی فقط به حالت local محدودند. تاریخچهٔ قیمت دادهٔ ساختگی تولید نمی‌کند؛ نبود دادهٔ تاریخی همچنان نبود داده گزارش می‌شود.

ابزار `tools/update-mainnet-ui.sh` در checkout جدید وابستگی‌ها و فایل وب را می‌سازد، سپس `tools/apply-mainnet-ui.py` hash سورس و خروجی را با `config/mainnet-ui-release.json` تطبیق می‌دهد. تنها یک مسیر static جدید با نام برگرفته از hash و نسخهٔ HTML پنل نصب می‌شود. `web/app.js` اصلی، سورس runtime، تنظیمات deployment و قراردادها دست‌نخورده می‌مانند؛ بنابراین fingerprint نسخهٔ دیپلوی‌شده حفظ می‌شود. نصب به restart نیاز ندارد.

قبل از تغییر HTML بکاپ و فرمان بازگشت ذخیره می‌شود؛ asset جدید باید روی HTTPS در دسترس باشد. سپس HTML به‌صورت atomic جایگزین و هر سه مسیر app/token/admin به‌همراه سلامت قرارداد بررسی می‌شوند. خطای پس از جایگزینی، HTML قبلی را بازمی‌گرداند. rollback روی HTML تغییرکرده توسط اپراتور اجرا نمی‌شود تا ویرایش او حذف نشود. فایل‌های نام‌گذاری‌شده با hash برای مرورگرهای دارای صفحهٔ باز باقی می‌مانند.

در پایان `tools/check-mainnet-keeper.py` فقط آدرس عمومی و موجودی BNB کیف پول Keeper موجود را روی شبکهٔ ۵۶ می‌خواند. کلید در سرور می‌ماند؛ کیف پول بدون provider ساخته می‌شود و هیچ تراکنشی امضا/ارسال یا سرویسی فعال نمی‌شود. جدا بودن آن از مالک، توسعه‌دهنده، دیپلوی‌کننده، شورا و ۳۱ جایگاه گزارش می‌شود. `hasGas=true` به‌تنهایی به معنی کافی بودن بودجهٔ مستمر نیست؛ موجودی و محدودیت هزینه باید پیش از فعال‌سازی بررسی شوند.

شواهد محلی: ساخت وب موفق؛ ۳۳ آزمون شبکه/رابط/ترجمه/قیمت موفق؛ دو آزمون نصب برای نگه‌داشتن مسیرهای CSS و جلوگیری از بازنویسی ویرایش هم‌زمان موفق. این گزارش ادعای نصب این اصلاح روی VPS، آزمون خرید واقعی، تأیید موبایل یا فعالیت Keeper ندارد. موجودی/کاربران تست‌نت مهاجرت نمی‌کنند و قرارداد یا منطق اقتصادی تغییر نکرده است.
