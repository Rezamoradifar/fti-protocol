# هماهنگی تم پنل کاربر با لندینگ FTI

مبنا: شاخهٔ Builder controls در commit برابر `92ece5bc11f3878d9470ec8a5c8b5976e0554c69`. مرجع ظاهر، `landing/src/initial-landing.css` و لندینگ اصلی است؛ نه تصویر فرضی یا نمودار ساختگی.

## تغییر واقعی فرانت

تم جدید در `frontend/member-landing-theme.css`، فقط روی `body[data-surface="member"]` اعمال می‌شود. پس‌زمینهٔ نزدیک به مشکی `#080d0b`، سبز نعنایی `#b2ffd0`، متن و رنگ‌های فرعی مطابق لندینگ هستند. نشان سه‌پله‌ای برند، تیترها، کادر معرفی، منو، کارت رتبه و موجودی، فرم‌ها، دکمه‌ها، بخش پاداش و درخت شبکه هم‌تم شده‌اند. حالت روشن از بخش روشن لندینگ الهام گرفته و انتخاب فعلیِ light همچنان اثر دارد؛ فارسی راست‌چین و انگلیسی چپ‌چین نگه داشته شده‌اند.

برای تلفن و تبلت، منو و کارت‌ها چیدمان متناسب دارند. اندازهٔ ورودی‌ها، نشانگر فوکوس صفحه‌کلید و حالت کاهش حرکت نیز در CSS مشخص‌اند. نام خانواده‌های فونت با مرجع هماهنگ است، اما این اصلاح هیچ فونت یا تصویر خارجی بارگیری نمی‌کند؛ در نبود فونت، جایگزین سیستم استفاده می‌شود. این عبارت به معنی تضمین یکسان‌بودن فونت نصب‌شده روی همهٔ دستگاه‌ها نیست.

فایل CSS با `npm run build:web` به `web/member-landing-theme.css` ساخته می‌شود و پس از style.css در HTML پنل بارگیری می‌شود. خروجی ساخته‌شده در gitignore است؛ منبع فرانت در همان دامنهٔ محاسبهٔ fingerprint موجود قرار می‌گیرد. هیچ کنترل صحت انتشار حذف نشده است.

## قسمت‌هایی که دست‌نخورده‌اند

این تغییر، فایل‌های main.jsx و controller.js، منطق اتصال کیف‌پول، فرم‌های تراکنش، قراردادها، API، Keeper، داده‌ها و موجودی کاربران را تغییر نمی‌دهد. شناسهٔ فرم‌ها و کنترل disabled/hidden قبلی حفظ شده است. انتخاب درصد اتوبای و پیام موعد ماه، تغییرات قبلی PR #21 هستند؛ این اصلاح فقط ظاهرشان را هماهنگ می‌کند. پوستهٔ توکن و پنل شورا و خود لندینگ از این CSS عضو تأثیر نمی‌گیرند.

ترجمهٔ کامل هفت زبان، لینک‌های رسمی شبکه‌های اجتماعی و تغییر منبع یا منحنی دادهٔ نمودار، در این اصلاح پیاده‌سازی نشده‌اند. همچنین هیچ انتقال دارایی یا نصب زنده روی سرور انجام نشده است.

## شواهد اجرا

- build واقعی وب و build لندینگ: موفق.
- کامپایل Solidity نسخهٔ مبنا: موفق؛ قرارداد تازه‌ای برای این تم نوشته یا دیپلوی عمومی نشده است.
- `node --test test/member-landing-theme.test.mjs test/continuity-deployment.test.mjs`: **۸ تست موفق، صفر شکست/حذف/لغو**؛ شامل ۷ آزمون پوسته و یک آزمون استقرار/API واقعی در EVM محلی. مسیر فایل CSS و Content-Type آن نیز با HTTP همان سرور پروژه بررسی شد.
- بررسی آفلاین Chromium از روی همان JSX و CSS: **۸۰ ترکیب نمایش موفق**، شامل فارسی/انگلیسی، روشن/تیره، عرض‌های ۳۲۰/۳۹۰/۷۶۸/۱۴۴۰ و پنج نمای overview/network/rewards/trade/activity؛ بیرون‌زدگی افقی صفحه در این نمونه‌ها مشاهده نشد. فوکوس صفحه‌کلید در ۱۶ ترکیب زبان/تم/عرض نیز بررسی شد.
- مرورگر محیط اجازهٔ رفتن به URL محلی را نداد؛ بررسی بصری با HTML/CSS/JS تزریق‌شدهٔ آفلاین انجام شد و controller تراکنش عمداً در bundle پیش‌نمایش خالی بود. بنابراین ۸۰ حالت، آزمون اتصال کیف‌پول، ناوبری واقعی controller، RPC یا تراکنش نیستند. تست API واقعیِ Node جداست.
- زوج‌رنگ‌های متن اصلی و متن فرعی روی سطوح منتخب در هر دو تم، نسبت کنتراست حداقل ۴٫۵:۱ دارند. این فقط یک بررسی محدود است و گواه انطباق کامل WCAG نیست. مرجع: W3C WCAG 2.2 Understanding، https://www.w3.org/WAI/WCAG22/Understanding/ .
