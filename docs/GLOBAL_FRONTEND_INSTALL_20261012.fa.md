# نصب فرانت یکپارچه روی سرویس فعلی ۳۱۱۰

این نصب، فرانت منتشرشده در `530e993957459cbc94a5b403d9b819171df19f8f` را روی همان سرویس فعلی قرار می‌دهد؛ نصب شبکهٔ تازه، ارتقای قرارداد، مهاجرت کاربران یا انتقال پشتوانه نیست. فرانت شامل انتخاب‌گر هفت زبان و ترجمهٔ متن‌های اصلی، تم اعضا مطابق لندینگ، نمودار مشاهدات قیمت قرارداد، وضعیت ماهانه و فرم سازگار با قابلیت قرارداد متصل است. ترجمهٔ متون تفصیلی هنوز کامل نیست. لینک حساب‌های اجتماعی تا دریافت آدرس رسمی خالی می‌ماند.

## فرمان نصب

در همان سرور با root اجرا شود. Python 3، curl، sha256sum، ss و Node 22 یا جدیدترِ سرویس و وابستگی‌های قبلی پروژه لازم‌اند. نصب‌کننده بستهٔ جدید نصب نمی‌کند؛ تغییر نسخهٔ وابستگی‌ها یا کد ناشناخته باعث توقف می‌شود. پورت ۳۱۰۸ با این فرمان تغییر نمی‌کند.

```bash
(
  set -euo pipefail
  umask 077
  REV='cbf7672ca648e7da9c328f12682b3600610e5244'
  FILE="$(mktemp /root/fti-global-frontend.XXXXXX.py)"
  curl -fL --retry 2 --connect-timeout 15 --max-time 120 \
    "https://raw.githubusercontent.com/Rezamoradifar/fti-protocol/$REV/tools/install-global-frontend.py" \
    -o "$FILE"
  printf '%s  %s\n' \
    'a0a9a48d33e1dbb383dd80b20fe535a0f0ccbfd610da217504f067f9103b892a' \
    "$FILE" | sha256sum -c -
  printf '\nINSTALLER_SAVED=%s\n' "$FILE"
  python3 -I "$FILE" --port 3110 --apply
)
```

خروجی موفق `FTI_GLOBAL_FRONTEND_INSTALLED` است؛ اجرای مجدد همان نسخه `FTI_GLOBAL_FRONTEND_ALREADY_INSTALLED` می‌دهد. `frontendRevision` باید 530e993957459cbc94a5b403d9b819171df19f8f باشد. backendRevision همچنان نسخهٔ قرارداد/API قبلی است و عمداً به شناسهٔ فرانت جعل نمی‌شود. contractsChanged، servicesRestarted و fundsMoved برابر false می‌مانند. مسیر backup و مسیر فایل نصب‌کننده را نگه دارید.

این فرمان نصب انجام می‌دهد، نه صرفاً build کاندید. پورت انتخاب‌شده باید همان سرویس متصل به دامنه باشد؛ نصب‌کننده nginx و مسیر دامنه را تغییر نمی‌دهد. پس از موفقیت صفحه را دوباره بارگیری کنید. در صورت خطا، متن خطا و خروجی نهایی کافی است؛ کلید، فایل .env و آرشیو کاربران منتشر نشود. ترمینال را تا پایان اجرا نبندید.

## چه چیزی تغییر می‌کند؟

ابزار پردازش واقعی سرویس و کد شناخته‌شدهٔ server.mjs را شناسایی می‌کند؛ محتوای HTML دیسک و HTTP را تطبیق می‌دهد و از نسخه‌های ناشناخته عبور نمی‌کند. ۴۳ ورودی ساخت از commit ثابت در پوشهٔ خصوصی جدا دریافت می‌شوند و هر فایل با SHA-256 مورد انتظار بررسی می‌شود. build وب و لندینگ با محیط متغیرهای مستقل و وابستگی‌های موجود اجرا می‌شود و ۳۸ تست فرانت/تم باید موفق باشند. محیط ساخت جدا، sandbox سیستم‌عامل برای کد یا وابستگیِ ناشناس نیست.

خروجی ساخت باید بایت‌به‌بایت با hash خروجی CI موفق 38236873534 تطبیق کند. سپس فایل‌های جدید در `web/fti-ui-530e99395745/` قرار می‌گیرند و فقط `web/index.html` و `landing/dist/index.html` به آن‌ها اشاره می‌کنند. HTMLها شناسهٔ فرانت مستقل و SRI برای JS/CSS دارند. کد سرور، Keeper، قراردادها، artifactها، فایل deployment، منابع قبلی و فایل‌های قدیمیِ تحت fingerprint، از جمله web/app.js و کتابخانه WalletConnect، بازنویسی نمی‌شوند. شناسهٔ انتشار قبلی تغییر نمی‌کند؛ برای فرانت جدید manifest مجزا ثبت می‌شود.

از HTMLهای قبلی، از جمله لینک تمی که قبلاً نصب شده بود، پیش از تغییر در `/var/backups/fti-global-frontend/install-...` بکاپ گرفته می‌شود. فایل‌های جدید پیش از تغییر HTML از HTTP آزمایش می‌شوند؛ پس از تغییر نیز مسیرهای پنل اعضا/توکن/شورا و لندینگ/وایت‌پیپر/نقشه راه، تنظیمات بدون تغییر و hash منابع حفاظت‌شده بررسی می‌شوند. جایگزینی هر HTML اتمیک است، نه یک تراکنش اتمیک مشترک بین دو فایل. خطای گرفته‌شده، تغییر HTML همین نصب را برمی‌گرداند؛ ویرایش هم‌زمان مدیر عمداً بازنویسی نمی‌شود. قطع برق یا SIGKILL ممکن است به اجرای بازگشت با backup نیاز داشته باشد.

## بازگشت

فقط در صورت نیاز به بازگشت، مسیر واقعی INSTALLER_SAVED و backup خروجی همان اجرا را به دستور بدهید. این‌ها نمونهٔ آرگومان هستند و باید با دو مسیر چاپ‌شده جایگزین شوند:

```bash
python3 -I /root/ACTUAL_INSTALLER.py --port 3110 \
  --restore /var/backups/fti-global-frontend/ACTUAL_BACKUP_DIRECTORY
```

بازگشت، HTML پیش از نصب را برمی‌گرداند و منطق مالی را تغییر نمی‌دهد. اگر تنظیمات backend، منابع حفاظت‌شده یا HTML بعداً تغییر کرده باشند، ابزار به‌جای overwrite کورکورانه متوقف می‌شود. فایل‌های immutable برای مرورگرهایی که HTML قبلی را نگه داشته‌اند باقی می‌مانند. این بکاپ، بکاپ فایل‌های فرانت است و جای خروجی کاربران/حسابداری یا بکاپ خارج از سرور را نمی‌گیرد.

## شواهد واقعی این ادامه

- کد نصب محلی دقیقاً با Git blob برابر `9ee2556e275f5d788a86683cb7b2f302ad6aece8` و SHA-256 فرمان بالا مطابق است.
- ۲۱ آزمون نصب‌کننده با دارایی‌های فرانت واقعاً ساخته‌شده موفق شدند: hash خروجی/ورودی، مسیرها، symlink، ویرایش هم‌زمان، خرابی HTTP، حفظ فایل‌های backend، مجوزهای فایل، نصب تکراری و بازگشت. بیشتر transport این مجموعهٔ واحد شبیه‌سازی‌شده است؛ آزمون مرورگر یا شبکهٔ عمومی نیست.
- اجرای اختصاصی GitHub `Global frontend installer` شماره 38239401055، job برابر 114777992489، روی head cbf7672ca648e7da9c328f12682b3600610e5244 با موفقیت پایان یافت. لاگ کامل خوانده شد: build واقعی پنل و لندینگ، ۳۸ تست فرانت/پوسته و ۲۱ تست نصب موفق، بدون شکست. checkout روی merge آزمایشی ce76d722d854a0c3e4a66eec1646b46a7ab42d8b بوده است. این اعداد تست Solidity یا ادعای پایان کل suite نیستند. نصب وابستگی CI همچنان ۳۶ هشدار قبلی، شامل ۵ critical، گزارش می‌کند.
- آزمایش جدا روی سرور واقعی Node محلی با blob همان server.mjs قدیمی a3bfcf8b3973fb3cad0ce03c5cff2ce560d71859 و قراردادهای قدیمی روی Ganache خصوصی انجام شد. شناسایی PID/پوشه، دریافت HTTP، build جدا، تطبیق بایت‌های CI، نصب روی HTML دارای تم قبلی، اجرای مجدد و بازگشت دقیق HTML موفق بودند. این Ganache شناسهٔ آزمایشی 97 داشت ولی هیچ ارتباطی با BNB عمومی یا دارایی کاربر نداشت.
- در همان محیط آزمایشی، سرور قدیمی بعد از نصب توسط harness آزمایش ری‌استارت شد؛ verify اولیهٔ انتشار و /health دوباره موفق بودند، بدون تغییر fingerprint. خود نصب‌کننده دستور restart ندارد. تمام فرایندهای آزمایش پس از پایان متوقف شدند.
- DNS محیط توسعه برای دریافت مستقیم GitHub برقرار نبود؛ در آزمایش integration فقط پاسخ آرشیو دانلود با همان بایت‌های source artifact تأییدشده جایگزین شد، نه پاسخ‌های HTTP سرور یا تابع build. hash همهٔ ورودی‌ها بررسی شد. دانلود واقعی codeload روی VPS کاربر هنوز مشاهده نشده است.
- تلاش مرورگر Chromium برای URL محلی با ERR_BLOCKED_BY_ADMINISTRATOR متوقف شد؛ بنابراین این ادامه آزمون اتصال کیف‌پول، اجرای controller در مرورگر زنده یا ظاهر نصب‌شده روی دامنه را تأیید نمی‌کند. شواهد بصری آفلاین قبلی جدا هستند.

## مرز مالی

فرانت، محدودیت‌های قرارداد نصب‌شده را عوض نمی‌کند. روی قرارداد قدیمی، اتوبای ۵٪ و سقف قیمت قدیمی باقی می‌مانند؛ انتخاب ۵ تا ۱۰۰٪ و رفتار جدید درخواست ماهانه فقط با قابلیت پشتیبانی‌شده قابل استفاده است. این فرمان امضا، دیپلوی، شورا، مهاجرت یا برداشت ندارد. هیچ نصب واقعی روی VPS کاربر از محیط ChatGPT انجام نشده است.
