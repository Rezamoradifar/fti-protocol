# لندینگ کامل‌تر FTI

- نمای CSS سه‌بعدی لایه‌دار توکن با چرخش دستی، توقف حرکت و احترام به reduced motion؛ بدون دانلود موتور سه‌بعدی یا مدل خارجی.
- بخش مستقل شبکه باینری و مثال تعاملی پوینت‌ها: ۱۵ چپ، ۲۰ راست، سقف ۵ → پرداخت ۵، فلش ۱۰، اختلاف ذخیره ۵. این مثال نرخ درآمد یا پیش‌بینی مالی نیست.
- معماری ذخیره/عرضه، عضویت و شورا، مسیر توسعه بدون وعده زمانی، و پیوند مستقیم معرفی کامل، نقشه راه و صفحه توکن.
- فونت‌های محلی Manrope و Vazirmatn، فارسی/انگلیسی، روشن/تاریک و موبایل حفظ شده‌اند.
- قراردادها، عملیات اقتصادی، پنل کاربر و تنظیمات کیف پول تغییر نکرده‌اند.

ساخت موفق؛ ۲۲ تست مرورگر موجود روی عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ و یک تست جدید کنترل سه‌بعدی، reduced motion و محاسبه‌گر موفق شدند. مرورگر محلی با `/tmp/chromium` اجرا شد. اجرای اولیه بدون تعیین این مسیر به دلیل نبود مرورگر پیش‌فرض انجام نشد. ۱۵ تست نصب اتمی، پشتیبان، قطع اجرا و بازگردانی نیز موفق شدند.

`bash tools/update-mainnet-landing.sh` از checkout جداگانه، Node 22 سرویس جاری را تشخیص می‌دهد، وابستگی‌ها و build لندینگ را آماده می‌کند و پس از بررسی قراردادهای اصلی، فقط `landing/dist` همان release فعال را با نصب‌کننده اتمی تعویض می‌کند. نسخه قبلی و assetهای صفحات باز حفظ می‌شوند. این مسیر به سورس دارای fingerprint، سرویس، Keeper یا قراردادها دست نمی‌زند.

نصب VPS و بررسی مرورگر روی دامنه اصلی هنوز انجام نشده است. موفقیت محلی به معنی انتشار نیست. نام مسیر backup در خروجی نصب چاپ می‌شود.
