# هماهنگی پنل و لندینگ

لوگوی اضافه از pseudo-element قدیمی CSS حذف شد. BrandMark مشترک در لندینگ و پنل، نشان دایره‌ای F و پیکان است. نوشته FTI PROTOCOL در تمام زبان‌ها ثابت می‌ماند. فونت محلی Manrope/Vazirmatn، پالت تیره/روشن لندینگ و کنترل‌های موبایل پنل هماهنگ شدند.

تغییر تم اکنون در React و مستقل از بارگذاری config/ABI انجام می‌شود؛ شکست خواندن قرارداد دیگر دکمه تم را از کار نمی‌اندازد. وضعیت و خطاهای اتصال مالی همچنان واقعی نمایش داده می‌شوند.

نصب overlay شامل JS، CSS و فونت‌هاست؛ ارتقا از نسخه پایه و overlay قبلی پشتیبانی می‌شود. شناسه نسخه از هش مجموع فایل‌ها ساخته می‌شود. فایل HTML پیش از تعویض پشتیبان می‌شود، فایل‌های قدیمی دست‌نخورده می‌مانند، نتیجه HTTP بررسی و در شکست بازگردانده می‌شود. فایل‌های اصلی runtime و قراردادها عوض نمی‌شوند.

بررسی محلی: ۱۶ حالت پنل در عرض‌های ۳۲۰/۳۹۰/۸۴۴/۱۲۸۰، فارسی/انگلیسی و روشن/تاریک؛ چهار حالت ۳۹۰ با کنترل رنگ نهایی دکمه‌ها نیز تکرار شد. این بررسی با داده شبکه ثابت و عدم دسترسی عمدی به API مالی بود؛ تأیید تراکنش اصلی نیست. ۳۳ بررسی منطق رابط و شبکه و دو بررسی overlay نیز موفق بودند. نصب سرور و بررسی عمومی پس از آن هنوز تأیید نشده است.

برای هماهنگی هر دو سطح، از یک checkout تمیز، ابتدا `bash tools/update-mainnet-landing.sh` و سپس `bash tools/update-mainnet-ui.sh` اجرا شود. هر مرحله پشتیبان و بررسی مستقل دارد.
