# تصمیم‌های نسخه آزمایشی FTI

این فایل تغییرات و تفسیرهای پیاده‌سازی را شفاف می‌کند. نسخه Word و شبیه‌ساز دریافتی هنوز مشخصات یکسان و بدون ابهام نداشتند. موارد این صفحه انتخاب‌های نسخه آزمایشی‌اند و تصویب نهایی اقتصادی مالک محسوب نمی‌شوند.

| موضوع | رفتار نسخه ۰٫۱ |
|---|---|
| واحد رتبه | حداقل حجم تاریخی تجمعی دو دست، برحسب Unit؛ B1=۱۰۰، B2=۲۰۰، B3=۵۰۰، B4=۱۰۰۰. سوختن امتیاز، سابقه را کم نمی‌کند. |
| حداقل تسویه | پنج واحد از آخرین تسویه موفق؛ دوره‌های کم‌فعالیت پول و حجم را نگه می‌دارند. |
| ساعت بدون تسویه | جفت‌های حجم مصرف نمی‌شوند؛ سقف ساعت‌های ازدست‌رفته جمع نمی‌شود. در نخستین تسویه موفق، یک سقف اعمال می‌شود. این انتخاب اقتصادی باید صریحاً تأیید شود. |
| رتبه و سقف | سقف بر اساس رتبه قبلی؛ ارتقای رتبه در پردازش دوره ثبت و از دوره بعد برای سقف مؤثر می‌شود. |
| Protection | سطح قبلی برای دوره جاری؛ مقایسه نسبت دقیق Pool/Points با ۲۰ بدون وابستگی به گردکردن. برابری یا عدم تسویه سطح را ثابت می‌گذارد. |
| پول خرد | در Point Pool باقی می‌ماند؛ حذف یا برداشت مدیریتی نمی‌شود. |
| تأخیر تسویه | ثبت‌نام/افزایش واحد پس از مرز ساعت تا پایان تسویه متوقف است. ساعت‌های بدون ورودی در زمان تأخیر فشرده می‌شوند. این محدودیت عملیاتی نسخه اول است. |
| مقیاس | صف انتشار به اجداد با حداکثر ۱۰۰ گام؛ حسابرسی و تخصیص به همه اعضا در Batch حداکثر ۱۰۰ عضو. تعداد تراکنش‌ها همچنان با عمق و جمعیت رشد می‌کند. |
| Genesis | ۳۱ آدرس یکتا در درخت کامل؛ صفر Unit اولیه. فقط پس از خرید واقعی Unit، واجد درآمد، رتبه و خرید توکن می‌شوند. حجم قبلی برای جایگاه بدون واحد حفظ می‌شود. |
| پرداخت | طلب در قرارداد ثبت می‌شود؛ انتقال به درخواست صاحب طلب انجام می‌شود. شکست انتقال حق او را حذف یا تسویه دیگران را متوقف نمی‌کند. |
| Auto-Buy | فقط درآمد دوره‌ای که عضو در شروع محاسبه Builder بوده است؛ ۵٪ به طلب خرید تبدیل می‌شود. Keeper خرید را جدا اجرا می‌کند. |
| تغییر تنظیمات Auto-Buy | در مراحل محاسبه و تخصیص دوره بسته است تا اندازه Batch نتیجه اقتصادی را تغییر ندهد. |
| شکست Auto-Buy | طلب باقی می‌ماند؛ صاحب آن می‌تواند آن را به طلب تتر تبدیل و برداشت کند. هیچ کس نمی‌تواند به کیف‌پول دیگری هدایت کند. |
| مجوز خرید | خرید دستی تجمعی؛ Auto-Buy مستثنا، مطابق کامنت شبیه‌ساز. انتقال هم مصرف مجوز نیست. فروش آن را بازیابی نمی‌کند. |
| افزایش ضریب | عملیات حاکمیتی با تأخیر؛ برای هر پله نیاز به قیمت فعلی حداقل ۱۰برابر milestone قبلی دارد. ضریب دوبرابر و دائمی است، حداکثر ۱۰۲۴. TWAP پیاده نشده؛ یک منبع قیمت مستقل برای محصول اصلی باید بررسی شود. |
| پنج دلار ثبت‌نام | ۸۰٪ صندوق تقویت ذخیره و ۲۰٪ صندوق کف، بدون Mint. طبق شبیه‌ساز، نه عبارت کلی Reserve در Word. |
| حمایت قیمت | انتقال داخلی صندوق به ذخیره؛ خرید توکن از بازار نیست و هیچ کف قیمت تضمین نمی‌شود. |
| قفل کوچک و خودکار | ۵۰۰۰ کیف‌پول جدید یا ۳۰ روز، هرکدام زودتر. مهلت زمانی جدید و پیشنهادی است. |
| Vesting | خریدی که مجموع خرید دستی را به ۵۰۰ تتر یا بیشتر می‌رساند، چهار بخش در ۲۰۰۰۰،۲۸۰۰۰،۳۶۰۰۰،۴۴۰۰۰ کیف‌پول بعد؛ هر بخش حداکثر ۹۰ روز. خریدهای قبلی بازقفل نمی‌شوند. |
| پایان فاز | تصادفی‌سازی و عقب‌بردن زمان حذف شده؛ شمارنده بعد از ۲۰۰هزار هم ادامه دارد. مهلت زمانی مانع قفل دائمی می‌شود. |
| تعداد قفل | حداکثر ۶۴ بخش فعال برای هر کیف‌پول؛ قفل‌های بالغ پیش از خرید پاک می‌شوند. |
| سقف مالکیت | یک درصد مجموع عرضه مجازی و واقعی، فقط زمان خرید/دریافت؛ کنترل اشخاص یا چندکیف‌پولی نیست. سقف موجودی بعد از سوزاندن دیگران الزاماً حفظ نمی‌شود. |
| سفارش جزئی | خرید/فروش نامعتبر کامل برگشت می‌خورد؛ پرکردن جزئی خودکار وجود ندارد. کاربر مقدار کمتری وارد می‌کند. |
| انتقال | فقط توکن آزاد، فقط به عضو دارای واحد؛ سه درصد سوخت. توکن دریافتی قفل تازه ندارد. انتقال به خود رد می‌شود. |
| فروش ممتد | پنجره دقیق ۵۰۰۰ کیف‌پول جدید با مجموع پیشوندی؛ خریدهای دستی و خودکار شمرده می‌شوند. حداقل ۱۰۰۰ تتر فروش و نسبت فروش/خرید ۱٫۳. |
| ماه | ماه میلادی UTC؛ پردازش ماه‌ها ترتیبی و پس از نهایی‌شدن دوره‌های لازم. آستانه کسب رتبه تا انتهای ماه ملاک است. |
| سهم Builder | snapshot ثابت، تقسیم مساوی با سقف ۲۰٪ برای هر نفر؛ دریافت مثبت یک‌باره در عمر. سهم صفر حق دریافت را مصرف نمی‌کند. |
| حاکمیت | پنج مالک ثابت، سه رأی؛ توقف اضطراری از شورا بدون تأخیر، بازگشایی و عملیات حساس از Timelock ۷۲ساعته. چرخش اعضای شورا در این نسخه نیست. |
| Pause | ثبت‌نام/Top-up یا خریدوفروش/انتقال بسته به قرارداد؛ طلب قبلی و پردازش تسویه قابل استفاده باقی می‌ماند. |
| ارتقا | قراردادها غیرProxy و فاقد ارتقای مستقیم‌اند. تغییر اقتصاد به قرارداد جدید و مهاجرت نیاز دارد. |
| ارز پایه | ۱۸ رقم اعشار و بدون مالیات انتقال. استقرار ارائه‌شده فقط MockUSD آزمایشی دارد. |

## تفاوت شبیه‌سازی با محصول واقعی

مدل مرجع فقط محاسبات و جریان وجه را بررسی می‌کند؛ قفل‌ها، پنجره فروش، تأخیر حاکمیت، Snapshot ماهانه و گس باید در EVM تست شوند. رشد قیمت سناریو، پیش‌بینی بازار نیست. ذخیره مجازی دارایی قابل برداشت نیست. بازخرید طبق منحنی به معنی تضمین اصل سرمایه، سود یا فروش به قیمت لحظه‌ای نیست.
